# 5024106_MADL

Small Dart and Flutter experiments, each kept in its own folder.

## Experiments

- [Experiment 2](experiment_2/Experiment_2.dart): interactive Dart web demo. Its page is [web/index.html](experiment_2/web/index.html).
- [Experiment 3](experiment_3/README.md): Flutter student profile form. App entry point: [lib/main.dart](experiment_3/lib/main.dart).
- [Experiment 4](experiment_4/README.md): Flutter student details form with validation and a submission screen. App entry point: [lib/main.dart](experiment_4/lib/main.dart).
- [Experiment 5](experiment_5/README.md): Flutter layout and navigation widgets. App entry point: [lib/main.dart](experiment_5/lib/main.dart).
- [Experiment 6](experiment_6/lib/main.dart): Flutter dashboard with a bar chart and network image.
- [Experiment 7](experiment_7/lib/main.dart): Flutter named navigation and gesture handling demo.
- [Experiment 8](experiment_8/lib/main.dart): JSON encoding and simulated file operations demo.
- [Experiment 9](experiment_9/lib/main.dart): Student records UI backed by the Supabase REST API.
- [Experiment 10](experiment_10/lib/main.dart): Production-oriented Flutter error handling and app example.

## Run a Flutter experiment

Install the Flutter SDK and Google Chrome, then run these commands from the chosen experiment folder (3–10):

```sh
flutter pub get
flutter run -d chrome
```
